# Кофейная Смена

Мини-сервис для управляющего кофейней: график смен бариста, журнал списаний и учёт выручки со средним чеком.

Проект основан на моём опыте управления точкой. Там смены, списания и выручка жили в разных таблицах и тетрадях. Здесь это одно место, где сразу видны деньги и причины потерь.

## Возможности

- **Обзор**: средняя выручка в день и средний чек с динамикой к прошлой неделе, сумма списаний за 30 дней, график выручки за 14 дней, разбивка списаний по причинам.
- **Смены**: недельный график с переключением недель, добавление и удаление смен.
- **Списания**: позиция, количество, сумма и причина (истёк срок, брак, ошибка приготовления, проработка).
- **Выручка**: ввод выручки и числа чеков за день, средний чек считается автоматически.
- Светлая и тёмная тема, адаптивная вёрстка.

## Зачем это управляющему

Разбивка списаний по причинам показывает, где теряются деньги: просрочка, ошибки или проработка напитков. На таких данных я сократил списания на своей точке на 30–35% и поднял средний чек с 280 до 310 ₽ за счёт допродаж.

## Стек

Один файл `index.html`: HTML, CSS, чистый JavaScript, график на SVG без библиотек.
Данные хранятся в `localStorage`. В облачной версии (Claude Artifacts) это общая база с синхронизацией между сотрудниками.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Как сделано

Проект собран в формате вайбкодинга с ИИ-ассистентом (Claude). Требования, метрики и сценарии взяты из моей работы менеджером кофейни.
