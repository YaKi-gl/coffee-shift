## 💡 О проекте

**Кофейная Смена** — веб-приложение для управляющего небольшой кофейней. В нём сведены три вещи, которые обычно живут в разных таблицах и тетрадях: **график смен**, **журнал списаний** и **выручка по дням**.

Проект основан на моём опыте **управляющего кофейней**: команда из 3 бариста, 5 поставщиков, ежедневный контроль выручки и потерь.

## 🎯 Для кого и зачем

| Кто | Какую задачу решает |
|---|---|
| **Управляющий точкой** | Видит выручку, средний чек и потери на одном экране, а не в трёх таблицах |
| **Владелец** | Понимает, куда уходят деньги: списания разбиты по причинам |
| **Бариста** | Видит свой график смен на неделю |

**Главная ценность:** разбивка списаний по причинам показывает, где теряются деньги (просрочка, ошибки приготовления или проработка напитков), и даёт основу для решений.

> 📉 На таком учёте я сократил списания на своей точке на **30–35%** и поднял средний чек с **280 до 310 ₽** за счёт допродаж.

## ✨ Возможности

### 📊 Обзор
- Средняя выручка в день и средний чек с **динамикой к прошлой неделе**
- Сумма списаний за 30 дней
- **График выручки** за 14 дней
- **Разбивка списаний по причинам**

### 🗓 Смены
- Недельный график с переключением недель
- Добавление и удаление смен, подсветка текущего дня

### 🗑 Списания
- Журнал: позиция, количество, единица измерения, сумма, причина
- Причины: истёк срок, брак, ошибка приготовления, проработка

### 💰 Выручка
- Ввод выручки и количества чеков за день
- **Средний чек считается автоматически**

### Общее
- 💾 Данные сохраняются в браузере
- 🌗 Светлая и тёмная тема
- 📱 Адаптивная вёрстка

## 🛠 Стек технологий

| Слой | Технология | Для чего |
|---|---|---|
| Разметка | **HTML5** | Структура страницы, вкладки, формы ввода |
| Стили | **CSS3** (Grid, Flexbox, Custom Properties) | Адаптивная сетка, недельный календарь, светлая и тёмная тема |
| Логика | **Vanilla JavaScript (ES-модули, ES2020+)** | Вкладки, расчёт KPI и динамики, агрегация списаний, формы |
| Графики | **SVG** (без библиотек) | График выручки с осями и подсказками, построенный вручную |
| Хранение | **localStorage** | Сохранение смен, списаний и выручки в браузере |

| Хостинг | **GitHub Pages** | Статический хостинг с автодеплоем из `main` |
| Разработка | **Claude (AI-ассистент)** | Вайбкодинг: генерация и доработка кода по моим требованиям |

> Без фреймворков и сборщиков: чистый JavaScript на ES-модулях, код разделён по слоям (см. «Архитектура»).

## ⚡ Быстрый старт

Проект использует ES-модули, поэтому его нужно открывать через локальный сервер, а не двойным кликом по файлу.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/YaKi-gl/coffee-shift.git
cd coffee-shift

# 2. Запустить локальный сервер (любой из вариантов)
npx serve .                 # Node.js
python3 -m http.server 8000 # Python

# 3. Открыть http://localhost:8000 (или адрес, который покажет serve)
```

Установка зависимостей не нужна.

## 🏗 Архитектура

Код разделён на слои с однонаправленным потоком данных:

```
 Пользователь ──▶ main.js (события, формы) ──▶ store.actions ──▶ services/storage
                                                     │
                                                     ▼
                                                store.state ──▶ components/*View ──▶ DOM
                                                     ▲
                                         services/metrics (расчёт KPI)
```

| Слой | Ответственность |
|---|---|
| `config.js` | Константы: причины списаний, единицы измерения, периоды отчётов |
| `store.js` | Единственный источник состояния. Изменения только через `actions` |
| `services/metrics.js` | Бизнес-логика кофейни: средняя выручка, средний чек, динамика неделя к неделе, списания по причинам. Чистые функции без DOM |
| `services/storage.js` | Слой хранения: сейчас `localStorage`, легко заменить на API |
| `components/` | Отображение: каждая вкладка и каждый виджет в своём файле |
| `utils/` | Общие функции: даты, деньги, безопасный вывод |
